# WhoIsOnline

Simple full-stack app:

- Backend: Express + SQLite + WebSocket for auth and online user updates.
- Frontend: React + Vite UI for login and live online users.

## Run

1. Backend

```bash
cd backend
npm install
npm run dev
```

2. Frontend

```bash
cd frontend
npm install
npm run dev
```

Open the frontend URL shown in terminal (usually http://localhost:5173).
